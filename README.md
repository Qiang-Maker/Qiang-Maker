### 📌 关于我 (About Me)

你好，我是 **徐强 (Qiang / Qiang-Maker)**，常驻浙江宁波。

我是一名 **AI 应用开发工程师 ｜ C# / .NET + Vue 全栈开发工程师**：
- 🏭 **工业实体底座（任我行 MES）**：长期参与管家婆辉煌小工单（MES）、云易开票等企业业务系统开发与维护，熟练运用 C# / .NET 与 Vue 承接老旧页面向现代框架迁移重构、前后端接口联调、数据大屏看板与生产异常排查；
- 🤖 **AI + 工业智能体探索**：在实体工单业务基础上主导探索 **AI + MES OnCall Agent**，将自然语言问题智能路由至内部知识检索、业务查询与监控/负载均衡辅助处理工具链；
- 🛍️ **跨境 AI 电商项目群实战**：主导设计**跨境家居 AI 电商智能体项目群**方案实践，落地包含售前自进化智能客服（RAG 分层检索 + Tool Calling 库存/物流调度）、多模态素材中枢（VLM / OCR / ASR 与 FFmpeg 自动化流水线）与基于 MCP 协议的共享 Agent 运行时；
- 📖 **知识沉淀与开源生态**：主理 [ai-handbook](https://github.com/Qiang-Maker/ai-handbook) 体系化大模型与智能体工程技术手册，持续跟踪并参与 LiteLLM、OpenHands 等顶级开源项目；
- 📬 **联系交流**：`xuqiang5250@163.com` ｜ GitHub: [@Qiang-Maker](https://github.com/Qiang-Maker)
