### 📌 关于我 (About Me)

你好，我是 **徐强 (Qiang / Qiang-Maker)**，常驻浙江宁波。

我是一名 **AI 应用开发工程师 ｜ C# / .NET + Vue 全栈开发工程师**，技术主线紧扣**实体工厂制造（MES）**与**智慧客运交通（AI Agent）**两大实体工程场景：
- 🏭 **工业实体与制造工单（MES）**：长期负责生产工单执行系统（MES）、企业开票等核心工业软件功能迭代与维护，精通 C# / .NET、Vue、SQL Server / PostgreSQL，主导工业软件现代化架构演进、车间级实时数据大屏看板与核心业务高可用保障；
- 🤖 **工业智能 OnCall Agent**：在实体车间工单业务基础上落地 **AI + MES OnCall 智能体**，将自然语言生产查询精准路由至企业内部工业知识库、设备负荷与监控排障工具链；
- 🚆 **智慧交通与客运大模型应用**：参与综合客运枢纽智能化建设，涵盖基于流式语音（ASR / TTS / RTC）的端云多模态服务机器人底座、客运垂直大模型应用落地、以及场站多模态智慧安检视频智能分析；
- 📖 **体系化沉淀与开源生态**：主理 [ai-handbook](https://github.com/Qiang-Maker/ai-handbook) 体系化大模型工程技术手册，持续跟踪并参与 LiteLLM、OpenHands 等顶级开源项目；
- 📬 **联系交流**：`xuqiang5250@163.com` ｜ GitHub: [@Qiang-Maker](https://github.com/Qiang-Maker)
